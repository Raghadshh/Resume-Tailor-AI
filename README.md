# Resume Tailor AI

A small AI project that helps tailor my resume to a job description using my own saved experience and project data.

## Version 1 Goal

The first version will:

1. Read my saved profile data from `profile_bank.json`
2. Accept a pasted job description
3. Use AI to choose the most relevant experience and projects
4. Generate a tailored resume draft
