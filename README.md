# Resume Tailor AI

An intelligent resume customization tool that uses AI to tailor your resume to specific job descriptions, maximizing your chances of getting noticed by applicant tracking systems (ATS) and hiring managers.

## Project Structure

```
Resume-Tailor-AI/
├── backend/          # Backend API and business logic
├── frontend/         # Frontend UI and user interface
├── data/             # Data files and templates
│   ├── profilebak.json              # Sample user profile backup
│   ├── sample_job_description.txt   # Example job posting
│   └── resume_template.txt          # Resume template
└── README.md         # Project documentation
```

## Features

- **AI-Powered Tailoring**: Uses AI to match resume content with job descriptions
- **ATS Optimization**: Ensures your resume is optimized for Applicant Tracking Systems
- **Multiple Formats**: Support for various resume formats
- **Profile Management**: Save and manage multiple resume versions
- **Job Description Analysis**: Automatically extracts key skills and requirements

## Getting Started

### Prerequisites
- Node.js 16+ (for frontend)
- Python 3.8+ (for backend)
- Git

### Installation

1. Clone the repository
```bash
git clone <repository-url>
cd Resume-Tailor-AI
```

2. Set up the backend
```bash
cd backend
# Follow backend setup instructions
```

3. Set up the frontend
```bash
cd frontend
# Follow frontend setup instructions
```

### Usage

1. Upload your resume in the frontend
2. Paste a job description
3. AI will analyze the job posting and suggest resume modifications
4. Review and apply suggested changes
5. Download your tailored resume

## Data Files

- **profilebak.json**: Sample user profile structure with skills, experience, and education
- **sample_job_description.txt**: Example job posting for reference
- **resume_template.txt**: Standard resume template for formatting
